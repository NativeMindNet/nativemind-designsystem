head.php — the entire stylesheet

table{ border:1px solid blue; border-collapse:collapse; } td{ padding:3px; white-space:nowrap; } .header{ background-color:#eeeeff; } .zebra{ background-color:#eeeeff; } #tooltip { padding: 4px; background-color: #eee; border: 1px solid #000; text-align: center; font-size: 13px; z-index:999}

No font-family anywhere in the panel — it renders in the browser default serif, and that is part of the look. No radius, no shadow, no hover state, no sticky header, no spacing scale.

.header and .zebra are the same value. The header row is not darker than the stripes; the only thing separating them is position.

Zebra is applied to even rows only, in the row tag itself:
<tr <?if($cnt%2==0)echo 'class="zebra"';?>>

Hierarchy inside a cell comes from stacked <font size=1> / size=2 sub-lines and valign="top", never from padding.

Column emphasis comes from bgcolor on individual header cells — #ccccff on a-o/a-i, m-o/m-i, ACD-o and #ddddff on ACD-i. Body cells stay unpainted.
