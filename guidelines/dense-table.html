Dense table

The operations panel shows up to 40 columns per SIM, so every device of the table has to earn its width: the zebra is a brand tint rather than a second grey, headers collapse to a 16px icon plus a two-line label, and one cell stacks up to four values at descending contrast. All values here are the shipping panel's — nothing rounded, nothing invented.

What makes it work

The zebra is a brand tint, not a grey. One hue, three ascending strengths, so they stack instead of fighting: a selected odd row still reads as selected, and no second neutral enters the palette.

Tokens: --adm-row-even, --adm-row-odd, --adm-head-bg, --adm-row-sel. Separators are cool-grey and near-invisible on purpose: rows --adm-row-line 12%, header --adm-head-line 20%, panel edges --adm-chrome-line 14%.

Icon-only headers. A 16px glyph above the label, plus an optional 10px second line, lets a 74px column carry a two-part name (ACDL / DATT). The glyph is the column's own status icon, so header and cells share one vocabulary.

Stacked cells, descending contrast. Up to four values in one cell, ranked by ink rather than by position: primary 12px #303F49 → secondary 10px #8A97A3 → tertiary 10px #B6B6B6 → alarm 12px bold #E5484D. Identifiers switch to mono 11px so digits align.

Icon stacks as a status column. Six 16px marks in a 2px-gap row replace six columns of text; each carries a title with the raw code. Order is fixed — captcha, multi-SIM, spec flag, direction, quality, operator — so the eye reads position, not just picture.

Group code drives the icon. 100–299 working (play / pause / wake / sleep), 333 high DATT, 334 low ACDL, 335 balance block, 336 SIM blocked, 300+ low ACDL, 400+ low balance, 500+ blocked. The number stays visible next to it — the icon is redundancy, not a replacement.

Density figures. Cell padding 7px 6px, header 8px 6px, row height ~30px with a single line and ~46px with a stack. Grid is display:grid with explicit grid-template-columns + min-width:max-content and one horizontal scroller, so column widths stay identical between the header row and every body row without a <table>.
