3 · Provenance & Shadow Upgrade

В оригинальном наборе 109 иконок построены на базе библиотеки Fugue Icons 3.5.6 (Yusuke Kamiyamane). Все ранее использовавшиеся варианты icons-shadowless заменены на канонические версии с мягкой тенью (icons/) для улучшения контраста и визуальной глубины на светлом фоне таблиц.

Fugue-derived (109) Статусы звонков, SMS, календарные дни, замок, воспроизведение, маяк, часы, QoS-эмоции, диагностические фазы. Все shadowless-версии обновлены до стандартных icons/.

Hand-drawn (117) Уникальные пиксель-арты оборудования и брендов, не имеющие аналогов в Fugue:

  • napravleine/* — 33 логотипа операторов.
  • usb/* — модели USB-хабов (D-Link, Hamma, 16-port, PCI).
  • rssi/* — шкалы уровня сотового сигнала (0…4).
  • tree/* — коннекторы дерева (sub, down).
  • dongle173, dongle1550, pl2303, msm — чипсеты модемов.

4 · План плавной миграции к оригинальным именам

Чтобы код админки и компонентов был стандартизирован, переход к оригинальным названиям выполняется в 3 шага без нарушения работы существующих таблиц:

  1. Единый реестр соответствий (Alias Reference Map): Все связи зафиксированы в машиночитаемом файле assets/adminka/adminka-to-fugue-map.json.
  2. Постепенная замена в компонентах: Новые экраны и компоненты обращаются к каноническим именам из assets/fugue/fugue-icons-3.5.6-src/icons/<name>.png или Fugue 2× (32×32).
  3. Обратная совместимость: Легаси-пути assets/adminka/<folder>/<file> остаются активными и служат псевдонимами (алиасами), предотвращая регрессии.

Пример функции-резолвера для JavaScript / TypeScript:

// Helper: Resolve legacy adminka icon to canonical Fugue path
import iconMap from '../../assets/adminka/adminka-to-fugue-map.json';

export function resolveIcon(pathOrName, { prefer2x = false } = {}) {
  const match = iconMap.find(item => 
    item.adminka_path === pathOrName || item.adminka_file === pathOrName
  );
  if (match && match.is_fugue) {
    return prefer2x && match.fugue_2x_path ? match.fugue_2x_path : match.original_path;
  }
  return pathOrName; // fallback to hand-drawn / custom mark
}
