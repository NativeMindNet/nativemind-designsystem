Text input — use for login (subscription URL, email) and search. Calm utility look: hairline ring that thickens to the brand accent on focus.

```jsx
<Field label="Subscription URL" placeholder="https://…" value={url} onChange={setUrl} />
<Field label="Email" error="Invalid address" value={email} onChange={setEmail} />
```

50px tall, 10px radius. Error swaps the ring + helper to `--danger`.
