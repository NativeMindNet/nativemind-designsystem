Metric tile — three across on the VPN Home stat bar, or grid cells on a TaxLien detail panel.

```jsx
<StatTile icon={<img src="assets/icons/icon-download.svg" width={24}/>} label="Download" value="42.6 MB/s" />
<StatTile label="ROI" value="12.5%" delta="+3.2%" deltaPositive align="start" />
```

`dim` greys it for the disconnected/off state. Value is 20/600 tabular-nums.
